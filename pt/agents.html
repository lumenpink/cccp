Diretrizes para Agentes de IA & `AGENTS.md`

O CCCP estabelece uma ponte padronizada e automatizada entre os mantenedores humanos e os agentes autônomos de IA (Google Antigravity, Claude, Copilot), governando as convenções do projeto via instruções centralizadas no AGENTS.md.

1. Sincronização de Templates Centralizados (`cccp agents`)

Em vez de manter instruções duplicadas manualmente em dezenas de repositórios, o CCCP pode baixar, validar e injetar a configuração local diretamente no AGENTS.md do projeto: 

# Atualizar o AGENTS.md local a partir da URL do template configurado:
cccp agents update

# Inspecionar variáveis de template pendentes e cobertura atual:
cccp agents vars

2. Resolução Interativa de Variáveis (`cccp set-av`)

Quando um template de AGENTS.md requer valores específicos do repositório (ex: comandos de teste, comando de build, stack tecnológica), o CCCP fornece um assistente interativo: 

# Executar assistente interativo para preencher as variáveis necessárias:
cccp set-av

# Inspecionar as variáveis configuradas atualmente:
cccp set-av --list
★ Protocolo de Zero Alucinação

Todas as variáveis preenchidas pelo cccp set-av são salvas localmente no .cccprc. Quando o comando cccp agents update é executado, essas variáveis são injetadas de forma determinística, impedindo que os agentes de IA façam suposições ou violem as regras do repositório.
