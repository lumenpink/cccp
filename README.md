Zero-dependency toolchain for Conventional Commits enforcement, predictive SemVer 2.0.0, portable Git hooks, multi-forge ticket synchronization, and AI agent directives.

---

## ⚡ Quickstart

```bash
# 1. Install globally into ~/.local/bin/cccp
curl -fsSL https://cccp.2lp.in | sh

# 2. Enter any Git project and install compliance hooks
cd my-project && cccp install

# 3. Commit with the interactive DD-TDD wizard
cccp commit
```
