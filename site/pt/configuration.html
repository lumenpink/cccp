Configuração Hierárquica

O CCCP aplica uma rigorosa cascata de configuração em 4 níveis inspirada na exatidão do Comitê de Planejamento Estatal (Gosplan), garantindo comportamento determinístico em repositórios locais e ambientes globais.

A Cascata Hierárquica de 4 Níveis

Prioridade 1: Variáveis de Ambiente (mais alta — sobrescritas temporárias)
Prioridade 2: Configuração Local (.cccprc na raiz do repositório)
Prioridade 3: Configuração Global ($XDG_CONFIG_HOME/cccp/config ou ~/.config/cccp/config)
Prioridade 4: Padrões de Fábrica do Gosplan (fallback determinístico)

Utilizando o Comando `cccp config`

Inspecionar Configuração

# Exibir a configuração resolvida ativa:
cccp config

# Exibir apenas valores globais:
cccp config --global

# Exibir apenas valores do repositório local:
cccp config --local

Atualizar Configurações

# Definir chave no .cccprc local:
cccp config tickets_provider codeberg

# Definir chave globalmente para todos os projetos:
cccp config --global cz_prompt_breaking true

Remover Configurações

# Remover chave local:
cccp config --unset tickets_provider

# Remover chave global:
cccp config --global --unset cz_prompt_breaking

Diretivas de Configuração Suportadas

Chave da Diretiva Descrição Valor Padrão Opções Permitidas / Exemplos
types Lista de tipos de commit permitidos 11 tipos padrão feat,fix,docs,style,refactor,perf,test,build,ci,chore,revert
strict_types Validação estrita dos tipos 1 1 (estrito), 0 (permite tipos arbitrários)
strict_scopes Validação estrita da lista de escopos 0 1 (validação estrita), 0 (permissivo)
scopes Lista de escopos permitidos Vazio (todos permitidos) api,ui,db,core,cli
tickets_provider Provedor de issues upstream Detectado automaticamente forgejo, github, gitlab, sourcehut
tickets_limit Limite teto de cota horária 55 Inteiro (até 60)
post_push_sync Sincronização pós-push automática Vazio tickets, agent, tickets,agent
pinned_version Fixa o verificador de atualização em versão exata Vazio Ex: 2.3.0
