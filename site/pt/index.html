★ Decreto de Início Rápido do Gosplan — Três Passos para a Conformidade Total

Execute estes comandos no seu terminal para ingressar no movimento Stakhanovista do Git:

# 1. Instalar globalmente no seu PATH (~/.local/bin/cccp)
curl -fsSL https://codeberg.org/lumenpink/cccp/raw/branch/main/cccp.sh | sh -s -- install -g

# 2. Entrar em qualquer repositório Git e ativar os hooks de conformidade
cd meu-projeto && cccp install

# 3. Criar seu primeiro commit em conformidade com o assistente interativo
cccp cz

☭ Ordem nº 227 — Formato do Conventional Commit

Todos os commits devem seguir rigorosamente a estrutura padronizada:

<tipo>[escopo opcional]: <descrição>

[corpo opcional]

[rodapé(s) opcional(is)]

Tipos padrão: feat (bump minor), fix (patch bump), docs, style, refactor, perf, test, build, ci, chore, revert. Mudanças que quebram compatibilidade (!) disparam elevação Major imediata.
