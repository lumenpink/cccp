Registro de Comandos da CLI

Referência abrangente para cada comando, opção e subcomando suportado pelo utilitário de linha de comando CCCP.

★ `cccp commit -i` / `cccp cz`

Assistente interativo de commits. Guia passo a passo na seleção do tipo, escopo opcional, mensagem, corpo detalhado e breaking changes.

# Iniciar assistente interativo:
cccp cz
# ou:
cccp commit -i

★ `cccp status`

Inspeciona o estado operacional completo do repositório Git:

  • Status da branch e rastreamento upstream.
  • Versão SemVer preditiva e contagem de commits à frente da tag.
  • Status de sincronização dos hooks instalados e versões correspondentes.
  • Valores de configuração ativos a partir do `.cccprc` e ambiente.
cccp status

★ `cccp lint []`

Valida mensagens de commit em um intervalo de revisões do Git (ideal para pull requests e CI):

# Validar commits da branch atual em comparação com origin/main:
cccp lint origin/main..HEAD

# Validar os últimos 3 commits:
cccp lint HEAD~3..HEAD

★ `cccp tag []`

Calcula a próxima versão segundo o SemVer, atualiza o arquivo VERSION, documenta o CHANGELOG.md e gera uma tag anotada no Git:

# Auto-bump preditivo:
cccp tag

# Versão explícita com anotação customizada:
cccp tag 2.3.0 --title "Lançamento Stakhanovista" -m "Meta entregue com antecedência"

★ `cccp push [...]`

Executa o git push padrão, valida a conformidade da versão via pre-push e dispara os hooks pós-push configurados.

cccp push origin main --tags

★ `cccp completion `

Gera scripts de autocompletar nativos para Bash, Zsh e Fish:

# Bash (adicionar ao ~/.bashrc):
eval "$(cccp completion bash)"

# Zsh (adicionar ao ~/.zshrc antes do compinit):
eval "$(cccp completion zsh)"

# Fish:
cccp completion fish > ~/.config/fish/completions/cccp.fish

★ `cccp soviet`

Exibe o emblema oficial soviético, a faixa da Ordem nº 227 do Gosplan e as diretrizes de trabalho Stakhanovista:

cccp soviet
