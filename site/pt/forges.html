Sincronização Multi-Forge & Tickets

O CCCP conecta seu fluxo de trabalho Git diretamente aos rastreadores de issues upstream, sincronizando automaticamente tickets abertos em um documento markdown local (.antigravity/tickets.md) para desenvolvedores e agentes autônomos de IA.

1. Forges Remotos Suportados

Ecossistema do Forge Domínios Suportados Identificação & Sondagem Ativa
Forgejo & Gitea codeberg.org, instâncias próprias Sonda /api/v1/version para servidores auto-hospedados
GitHub github.com, GitHub Enterprise Utiliza a API REST v3 do GitHub, filtrando pull requests
GitLab framagit.org, gitlab.com, customizados Sonda /api/v4/version e suporta subgrupos aninhados
SourceHut git.sr.ht, *.sr.ht Extrai issues via GraphQL do tracker SourceHut

2. Sincronizando Tickets (`cccp tickets`)

# Sincronizar tickets com detecção automática do remote:
cccp tickets

# Forçar driver de forge específico:
cccp tickets --provider forgejo

# Informar proprietário e repositório explicitamente:
TICKETS_OWNER=meutime TICKETS_REPO=meuprojeto cccp tickets

3. Proteção de Cota Horária do Gosplan

★ Controle de Taxa Deslizante de 1 Hora

Para evitar o esgotamento de limites de requisições em APIs públicas (como o teto de 60 requisições/hora do GitHub sem autenticação), o CCCP rastreia as chamadas em .git/cccp_tickets_rate_limit:

  • Teto Padrão: Máximo de 55 requisições em janela deslizante de 1 hora.
  • Garantia de Não-Interrupção: Ao atingir o limite, o CCCP encerra suavemente com código 0 e emite aviso do Gosplan, sem interromper o git push ou pipelines de CI.
