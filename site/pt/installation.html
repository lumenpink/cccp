Instalação & Implantação

O CCCP pode ser implantado em dois modos complementares: globalmente em toda a sua estação de trabalho, ou localmente dentro de repositórios Git individuais via wrappers portáteis de hooks.

1. Instalação Global (PATH do Sistema)

Instalar o CCCP no PATH do seu sistema torna o executável cccp acessível universalmente a partir de qualquer diretório ou terminal: 

# Baixar e instalar em ~/.local/bin/cccp (ou /usr/local/bin/cccp se executado como root)
curl -fsSL https://codeberg.org/lumenpink/cccp/raw/branch/main/cccp.sh | sh -s -- install -g

Caso já tenha clonado o repositório localmente: 

./cccp.sh install --global
★ Verificação Automática de PATH

Se ~/.local/bin não estiver presente no seu $PATH, o instalador adiciona automaticamente o comando de exportação no seu ~/.bashrc (e ~/.zshrc se encontrado) com orientações claras.

2. Instalação Local de Hooks no Repositório

Em qualquer projeto Git, você pode instalar wrappers portáteis sem alterar diretórios do sistema: 

cd meu-repositorio-git
cccp install

Isso configura quatro hooks essenciais em .git/hooks/:

  • commit-msg: Valida a sintaxe da mensagem antes que o commit seja concluído.
  • post-commit: Atualiza o CHANGELOG.md e sincroniza a versão de desenvolvimento preditiva no VERSION.
  • pre-push: Impede que tags de release sejam enviadas sem o arquivo de versão devidamente sincronizado.
  • reference-transaction: Bloqueia a criação de tags que apontem para commits fora de conformidade ou versões de desenvolvimento.

3. Segurança & Backups Não-Destrutivos

Sempre que o cccp install encontra hooks pré-existentes não criados pelo CCCP, ele cria cópias de segurança automáticas com sufixos incrementais (ex: commit-msg.old) para que nenhuma regra personalizada seja perdida.

4. Desinstalação

# Remover hooks do Git no repositório atual:
cccp uninstall

# Remover o executável global:
rm -f ~/.local/bin/cccp
