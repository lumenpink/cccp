☭ Order No. 227 — Conventional Commit Format

All commits must adhere strictly to the standardized format:

<type>[optional scope]: <description>

[optional body]

[optional footer(s)]

Standard types: feat (minor bump), fix (patch bump), docs, style, refactor, perf, test, build, ci, chore, revert. Breaking changes (!) trigger an immediate Major version bump.
